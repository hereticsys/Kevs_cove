To play Playstation 3 games

1. Extract the rpcs3 compressed file to a folder
2. Download the .pup file
3. Download the ROM(S) of your choice

Your ROM is likely downloaded as multiple .part files. Download all the parts and join them here:
https://pinetools.com/join-files 
Once your file is joined itll be a large .7z or .zip folder
4. Extract your folder
5. Open the RPCS3 program
6. Click OPEN > Select the ROM folder
7. The program will prompt you to select the .PUP file. Select that file.

|This project uses RPCS3. Go here for more information:
https://rpcs3.net/quickstart
